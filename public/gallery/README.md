# Gallery photos

Place hospital and team photographs in this folder, then set the matching `src` field in `components/site/gallery.tsx`:

- `/gallery/hospital.jpg` — hospital or unit photo
- `/gallery/nurses.jpg` — nurses and care team
- `/gallery/patient-care.jpg` — patient care
- `/gallery/clinical-spaces.jpg` — consultation or treatment spaces
- `/gallery/laboratory-ultrasound.jpg` — laboratory or ultrasound facilities

Gallery cards show branded photo slots until an image path is added.
